# Changelog

## 1.0.0 (2026-10-19)

First public release.

- Sequential numbering of the certificates issued by Custom certificate, printed by the Code and QR code elements.
- Configurable prefix, yearly series, digits and random check characters.
- Certificate ledger with filters, search and export in every enabled format.
- Annulment with reason, deletion of copies and optional block on a new issue.
- Scheduled reconciliation and command line backfill.
- Privacy API: export, and anonymisation on deletion requests (default) or retention as a record.
